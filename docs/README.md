# Ticketing Queueing Application — Website

A responsive static landing page showcasing the Ticketing Queueing Application.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.

No build tools or server are required.

## Publish with GitHub Pages
1. Create a repository for the website (or use an existing website repository).
2. Upload `index.html`, the `assets` folder, and this README.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch (usually `main`) and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Download destination
All Download buttons point to:
https://github.com/TheDirtiestRat/ticketing_quequeing_application_flutter/releases/tag/v2.5

The website does not host the installer; visitors download it from the GitHub release Assets section.

## Customize
Edit `index.html` to change the title, wording, features, colors, or GitHub links. Replace the two PNG files in `assets` to update the screenshots.
